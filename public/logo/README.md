# Logo files go here

Place your Bogd Automall logo files in this folder:

- `logo.svg` — preferred, scalable, used in the site header/footer
- `logo.png` — fallback / used for social sharing previews if no SVG
- `favicon.ico` — replace `src/app/favicon.ico` with the real favicon when ready

Recommended sizes:
- Header logo: SVG (any size, scales automatically)
- Social share image (og:image): 1200x630px PNG or JPG, place in `public/images/`
